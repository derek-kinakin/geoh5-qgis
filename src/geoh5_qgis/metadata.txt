qgisMinimumVersion=4.0

description=Browse geoh5 (GEOSCIENCE ANALYST) files and add their objects as layers.
about=Expands .geoh5 files in the Browser panel and loads Points, Curve, Surface, Grid2D, GeoImage and drillhole group objects as layers, keeping the geoh5 file as the source of truth. Data channels keep their types, units and value maps, and layers open coloured as in GEOSCIENCE ANALYST. Reads files with GDAL, which ships with QGIS; no extra Python packages are needed.

changelog=0.2.0
    - Points, curves, drillholes and surface polygons are drawn at their true elevation in 3D views, coloured like their 2D style
    - Curves without data load as whole lines; curves with data keep segments, shaded continuously by a shown vertex channel
    - Drillhole interval data is typed like other data (keys and labels, units, GA colours)
    - Drillhole depth tables load as point layers on the holes
    - Large GeoImages get overviews for faster drawing
    0.1.0
    - Data channels keep their geoh5 types (Boolean, DateTime), units and value maps; referenced data adds a <name>_label field
    - Layers open coloured as in GEOSCIENCE ANALYST, from the shown channel's colour map
    - Grid2D loads one styled raster per channel; the Browser lists each grid's channels
